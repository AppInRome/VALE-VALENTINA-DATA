# Modelli locali

I modelli sono candidati, non scaricati né collaudati su Android. Nessun peso, binario o token viene pubblicato. E5 usa una copia locale del modello; llama.cpp richiede un eseguibile e GGUF compatibili. Gemma richiede verifica delle condizioni d'uso e del runtime. WordNet produce suggerimenti da revisionare, mai sostituzioni automatiche. Le integrazioni sperimentali non attivano costi cloud.
