# Android reader V2 contract
A production reader must pin an Ed25519 public key in the APK (not fetched with the pack), verify the exact manifest bytes before parsing, enforce monotonically increasing signed revisions, supported schema, size limits, allowed filenames and SHA256 for every resource, reject traversal and symlinks, stage downloads in private app storage, then atomically switch a version pointer after validation. Preserve last-known-good pack. Never execute downloaded code. The present repository does not contain the Android app; this is a contract, not an installed reader.
